# Primary Teacher Pro

Скилл для Codex: подготовка и проверка уроков, учебных игр, рабочих листов, карточек и оценочных материалов для начальной школы и K–12.

## Возможности

- Планирование уроков с наблюдаемыми результатами обучения.
- Учебные игры и задания с готовыми инструкциями и ответами.
- Формирующее оценивание, критерии и дифференциация.
- Адаптация к языку, возрасту и заданной учебной программе.

## Установка

Попросите Codex установить скилл из этого репозитория через `$skill-installer`, указав ссылку `https://github.com/vladrepeha/primary-teacher-pro` и путь к скиллу `.`. Либо скопируйте содержимое репозитория в папку `~/.codex/skills/primary-teacher-pro/`.

## Использование

```text
Используй $primary-teacher-pro: подготовь урок математики для 2 класса
на 45 минут по сложению в пределах 100. Добавь задания для учеников
и отдельный ключ с ответами для учителя.
```

Укажите класс или возраст, предмет, тему, язык и нужный формат материала. Скилл поддерживает автоматический выбор по подходящим запросам.

## Состав

`SKILL.md` содержит основные инструкции; `references/` — руководства по проектированию уроков, играм, оцениванию и проверке материалов; `agents/openai.yaml` — метаданные для интерфейса Codex.
