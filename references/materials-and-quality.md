# Student materials, answer verification, and production QA

Use for printable task cards, worksheets, handouts, quizzes, teacher keys,
visual resources, and any request to check whether materials are classroom-ready.

## Content before layout

Confirm:

- Target topic and age/grade; task count; individual or group use.
- Whether this is one sheet, multiple cards, a game board, a teacher key,
  or an editable file.
- Expected child response: mark, draw, circle, write, calculate, explain,
  cut, sort, or build.
- How much content fits the available time and writing space.
- Whether an answer should be unambiguous or allow justified alternatives.

Write all task text and check it before visual production. Do not hide missing
questions behind placeholders such as "Add more problems here."

## Student-facing material rules

- Begin with short, actionable instructions in the language of the classroom.
- Use familiar contexts without stereotypes or inappropriate adult problems.
- Give sufficient writing/drawing space and avoid tiny dense text.
- Keep answer cues, teacher directions, and solution keys off the student page
  unless explicitly requested.
- Number and count items; ensure different cards are actually different.
- For cut-out cards, each unit must make sense after separation.
- Use accurate headings, units, punctuation, diacritics, and answer fields.
- Prefer accessible contrast and legible type; use images only where they
  improve comprehension. Do not impose a fixed page format on the user.

## Mathematical correctness

- Solve **every** item independently and verify its answer.
- Check that values fall in the requested range (e.g., 0–100), including
  intermediates if that is part of the assignment.
- Validate units, text-to-equation correspondence, and constraints.
- For subtraction and division, check whether negative or fractional
  answers were intended; do not introduce them by accident.
- Avoid contextual impossibilities (half a child, more objects removed than
  present) unless the contradiction is the explicit problem.
- Distinguish "unique correct answer" from "multiple defensible strategies".
- Use computation or code for large/generated sets when available, then
  verify that the wording maps to the same computation.

## Literacy, science, and ethical-content correctness

- Verify quotations, historical facts, science claims, and attributed
  authorship with trusted sources when precision matters.
- Do not fabricate textbook excerpts, page numbers, standards codes, or
  copyrighted source passages.
- Check that reading questions can be answered from the supplied text and
  that inferential questions have actual supporting evidence.
- Separate observation from interpretation in science activities.
- Avoid prompts requiring sensitive disclosures from children.

## Deliverable structure

- A **teacher guide** may contain timing, setup, model responses,
  misconceptions, observation points, differentiated prompts, and answers.
- A **student sheet** should contain only what the learner needs to act.
- If both are requested, create separate clearly labeled sections/files.
- For cards, support 1-per-child distribution without duplicated text
  unless repeats are explicitly requested.
- For image-led materials, check that pictures do not change the content
  or accidentally reveal answers.

## Production verification

Before delivering, check:

1. Exactly the requested number of tasks, cards, pages, or versions exists.
2. Directions, examples, tasks, and answer keys agree.
3. No text is clipped, too small, overlapped, or cut off in preview.
4. Writing spaces, cut lines, and margins are usable in the intended output.
5. Student and teacher materials are not accidentally mixed.
6. The output file opens and is readable; use the corresponding artifact
   skill's render-and-inspect workflow for Word/PDF/slides/images.

If an actual printable file cannot be produced, provide complete structured
source content and explicitly say what artifact was not created.
